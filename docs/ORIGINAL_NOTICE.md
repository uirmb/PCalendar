我保留原作者与“数据或算法来源于寿星天文历”的来源说明，保留天文常数、级数项、历史气朔订正表与农历排月算法，围绕类型、模块、浏览器接口和界面进行迁移。测试用原版 JavaScript 位于 `tests/fixtures/original/`，仅作为隔离的比对基准，不参与浏览器生产构建。
